# AI챔피언 BLACK

양산시 지방전산주사 오대웅의 명함 QR 연결용 활동 소개 페이지입니다.

- 웹사이트: https://daeung79.github.io/MeetMe/
- 현안 상담 · 업무자동화 강의 · 워크숍: odw0902@korea.kr

확정한 명함의 앞·뒷면 문구를 바탕으로 소개, AI 연구 스킬, 연구·수상 활동을 정리했습니다. 명함의 인증번호는 임시데이터이므로 웹페이지에 게시하지 않았습니다.

GitHub Pages는 main 브랜치의 루트에서 배포합니다.

## 명함 편집기

`editor.html`에서 앞·뒷면 문구를 한 번 수정하면 3개 시안에 동시에 반영됩니다. QR등록 탭에서는 세 시안 뒷면의 QR 이미지를 교체할 수 있습니다. 앞·뒷면 완성 이미지 등록은 지원하지 않습니다. 각 면을 86 × 52mm, 600dpi PNG로 내려받을 수 있습니다. PNG에는 인쇄 크기용 DPI 정보가 포함됩니다. 편집 내용은 현재 브라우저의 로컬 저장소에만 보관되므로 다른 기기와 자동 동기화되거나 GitHub 파일이 수정되지는 않습니다.
